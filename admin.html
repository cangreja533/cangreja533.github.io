Panel de contenido del sitio

Edita los textos principales de index.html sin tocar código. Al aplicar los cambios se crea automáticamente un Pull Request en el repositorio para publicarlos.

0. Conexión con GitHub

Crea un token de acceso personal (fine-grained) en github.com/settings/tokens, con acceso limitado a este repositorio y permisos de "Contents: Read and write" y "Pull requests: Read and write". El token se guarda solo en este navegador (localStorage) y se envía únicamente a api.github.com; no lo compartas ni lo uses en un equipo público.

Si abres este panel directamente desde tu computador (file://) el navegador puede bloquear la carga automática; en ese caso usa "Cargar desde archivo…" y selecciona tu index.html. Si lo abres desde el sitio publicado, "Cargar contenido actual" funciona directo.

Aún no se ha cargado ningún contenido. Usa "Cargar contenido actual" o "Cargar desde archivo…" arriba antes de editar.

3. Guardar cambios

"Aplicar y crear Pull Request" actualiza la vista previa y, tras confirmar, crea una rama nueva en GitHub con estos cambios y abre un Pull Request contra la rama base para revisarlos antes de publicarlos. "Descargar" sigue disponible como respaldo manual si prefieres subir el archivo tú misma.
